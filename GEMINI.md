# Project Guidelines & Rules

This project is a React Native (Expo) mobile application for Android and iOS.

## Frontend AI Skills (Mandatory)

Always use the **Frontend AI Skills** (`frontend-ai-skills` installed in `.agents/skills/`):
- For any frontend architecture, UI/UX, React/React Native component design, styling, state management, animations, performance, or accessibility task, route and adhere strictly to the guidelines defined in the corresponding skill (following the contract in `70-frontend-skill-router`).
- Key focus areas:
  - `01-frontend-architecture` & `10-component-engineering`: Modular architecture, clean boundaries, cohesive components.
  - `02-react` & `04-typescript`: Safe, lifecycle-aware, type-safe React code without runtime errors.
  - `07-responsive-design` & `08-ui-ux-design`: Mobile-first responsive layouts, appropriate touch targets, hierarchy, and affordances.
  - `11-accessibility`: Accessible controls, screen reader support, keyboard and tap handling.
  - `14-state-management` & `15-data-fetching`: Minimal state complexity, resilient loading and error handling.
  - `17-frontend-performance` & `51-animation-performance`: Maintain 60fps, avoid unnecessary renders, clean up observers and listeners.
